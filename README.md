# Mini Gestor de Tareas Inteligente

Aplicación web simple para gestionar tareas, construida con **Python** y **Flask**. Al completar una tarea, se consume la API pública [Advice Slip](https://api.adviceslip.com/) para mostrar un consejo motivador.

## Tecnologías utilizadas

- **Python 3.x** – Lenguaje de programación.
- **Flask** – Microframework web para el servidor y las rutas.
- **Requests** – Biblioteca para consumir la API externa.
- **HTML + CSS** – Interfaz embebida en una sola plantilla.

## ¿Por qué estas herramientas?

- Flask es ligero, ideal para prototipos rápidos y no requiere configuración compleja.
- Requests simplifica las peticiones HTTP a la API.
- La interfaz embebida en una plantilla permite tener todo en un solo archivo, facilitando la distribución.

## Requisitos previos

- Tener **Python 3.6+** instalado.
- Conexión a Internet (para instalar dependencias y consumir la API).
- (Opcional) Git para clonar el repositorio.
